ZeroC supports IceRPC for C# on the following platforms:

## Windows

| OS             | Version | Architectures | .NET version |
| -------------- | ------- | ------------- | ------------ |
| Windows 11     | 26H1    | x64           | .NET 11.0    |
| Windows Server | 2025    | x64           | .NET 11.0    |

## Linux

| OS                       | Version      | Architectures | .NET version |
| ------------------------ | ------------ | ------------- | ------------ |
| Debian                   | 13           | x64, Arm64    | .NET 11.0    |
| Red Hat Enterprise Linux | 10           | x64, Arm64    | .NET 11.0    |
| Ubuntu                   | 24.04, 26.04 | x64, Arm64    | .NET 11.0    |

## macOS

| OS    | Version          | Architectures | .NET version |
| ----- | ---------------- | ------------- | ------------ |
| macOS | 27 (Golden Gate) | Arm64         | .NET 11.0    |

## Other platforms

ZeroC provides support on a best effort basis—without any guarantee—for all other [.NET 11.0 platforms].
